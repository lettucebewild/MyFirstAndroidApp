MyFirstAndroidApp  (Java, UI only)

1. Android Studio > File > Open > select the MyFirstAndroidApp folder. Wait for Gradle sync.
2. In the toolbar's run-configuration dropdown, pick "app" > Edit Configurations... >
   Launch Options > Launch: "Specified Activity" > choose LoginActivity or ProfileActivity.
   (Tip: duplicate the config so you have two: "Login" and "Profile".)
3. Press Run on an emulator or a phone.
   The phone will also show two icons: "SIS Login" and "SIS Profile".
